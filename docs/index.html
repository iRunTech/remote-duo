Pairing

Paired in the time it takes to read a PIN.

Remote Duo finds computers running the host on your Wi‑Fi. Pick one, enter the PIN from its menu, and you're in. Or scan the host's QR code with the Camera app.

Away from home? Run Tailscale on both devices and connect by its address.

FAQ

Questions before you install

Does it work away from home?

Yes. Install Tailscale on your phone and computer, then connect using the computer's Tailscale address.

Which computers does it support?

macOS 13 or later (Apple silicon and Intel), Windows 10 or 11 (64-bit), and Linux on x86_64 or ARM64.

Is it safe to let my phone control my computer?

Your phone pairs with a PIN and pins the computer's certificate, the connection is encrypted, and it never leaves your network unless you set up Tailscale. There are no Remote Duo servers.

Why does Windows warn me about the download?

The Windows host isn't code-signed yet, so SmartScreen shows "Windows protected your PC." Click More info, then Run anyway. The host is open source, and you can check the code on GitHub.

Do I need iPhone Duo?

No. Any iPhone works as a trackpad, keyboard and remote. iPhone Duo adds the live screen above the trackpad.

Can I sign in to a locked computer from my phone?

Yes. On a Mac, the lock screen works as-is. On Windows, the host installs a small "Remote Duo Sign-in Helper" service so you can see the sign-in screen and type your password from your phone. It only works at the sign-in screen, so it can't approve admin prompts. Windows hides the cursor on the PC's own screen at sign-in, but it shows in screen view on your phone.

What happens when my computer restarts?

Turn on Start Automatically in the Remote Duo menu and the host comes back by itself. On Windows, your phone can reach the sign-in screen right after a restart, before anyone signs in. On a Mac, it's back as soon as you're logged in, including after macOS update restarts. A Mac with FileVault turned on asks for its password at startup after an unexpected restart (a crash or power cut), before macOS loads. No remote app can reach that screen, so type it at the Mac.
